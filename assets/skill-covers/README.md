# Skill cover assets

The cover generator embeds these files into a local HTML template.

- `avatar.jpg` is the saved GitHub avatar for Unique-Divine, retrieved on
  October 19, 2026 through the GitHub users API.
- `Archivo.ttf` is Archivo Black at weight 900, downloaded through Google
  Fonts. Its license is in `Archivo-OFL.txt`.
- `JetBrainsMono.ttf` is JetBrains Mono at weight 500, downloaded through
  Google Fonts. Its license is in `JetBrainsMono-OFL.txt`.

Typography follows the Archivo/JetBrains Mono pairing in sai-web docs-app's
Herdr OG card examples. Layout references include Stripe's editorial blog
covers. The template and graphic elements are maintained in this repository.
